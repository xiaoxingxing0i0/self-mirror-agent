## Agent 池定义
### 2.1 DP 动态规划调度 Agent（Dynamic Planning Scheduler Agent）

#### 核心定位

系统的全局中枢与调度核心，负责全链路的请求分发、流程编排、状态同步与会话管理，是所有 Agent 交互的唯一中转节点。

#### 核心职责

1. 接收用户所有输入请求，完成会话上下文的初始化、维护与销毁
2. 基于用户意图动态编排各 Agent 的执行顺序与依赖关系，规划最优执行链路
3. 接收各 Agent 的执行结果，进行结果聚合、状态同步与流程推进
4. 负责全量对话记录（用户输入 + 系统回复 + 标签元数据）的结构化存储与会话生命周期管理
5. 处理 Agent 执行异常，执行降级、重试、熔断等容错逻辑
6. 维护全局任务状态，向用户同步任务进度与最终执行结果

#### 核心能力

- 多意图识别与执行链路智能路由
- 多轮对话上下文管理与记忆继承
- 动态流程编排，支持串行、并行、分支执行模式
- 全局状态同步与异常兜底处理
- 对话日志全量结构化归档

#### 输入输出规范

表格

| 输入 | 输出 |
| --- | --- |
| 用户原始输入内容 | 分发给对应 Agent 的执行指令与入参 |
| 各 Agent 返回的执行结果与状态 | 最终返回给用户的响应内容 |
| 会话上下文数据 | 结构化的会话归档与元数据 |

#### 交互对象

所有业务 Agent（语言分析 Agent、用户对话 Agent、检索 Agent、任务执行 Agent、合规检查 Agent、用户画像与报告 Agent）

#### 触发场景

- 用户发起新的对话请求
- 任务执行 Agent 产生状态更新
- 单个 Agent 执行完成返回结果
- 会话生命周期触发（创建、续期、结束）

#### 异常处理

- 单个 Agent 执行失败时，根据业务等级执行重试或降级返回
- 链路超时时，返回兜底响应并记录异常日志
- 合规校验不通过时，拦截输出并触发重生成逻辑

### 2.2 语言分析 Agent（Language Analysis Agent）

#### 核心定位

系统的语义理解与意图分类核心，负责对用户输入进行全维度语义解析，输出结构化标签体系，为后续调度、检索、画像构建提供数据基础。

#### 核心职责

1. 对用户对话内容进行情绪识别，输出细粒度情绪标签与情绪强度分值
2. 识别用户输入的意图类型：日常对话、信息查询、建议咨询、任务指令
3. 提取对话中的心理特征、认知模式、行为倾向等心理标签
4. 对任务类需求进行任务类型标注（报告生成、数据统计、定时提醒等）
5. 识别需要调用 RAG 知识库的咨询场景，打上建议需求标签

#### 核心能力

- 细粒度情绪识别（覆盖正 / 负 / 中性大类，细分开心、焦虑、低落、愤怒、平静等 20 + 子类）
- 用户意图分类与任务类型精准识别
- 心理特征抽取（自尊水平、归因风格、应对方式等）
- 多轮对话语义连贯性分析
- 标签置信度评估与校验

#### 输入输出规范

表格

| 输入 | 输出 |
| --- | --- |
| 用户原始对话文本 | 结构化标签集：情绪标签、意图标签、心理标签、任务标签、建议标签 |
| 会话上下文文本 | 各标签的置信度分数 |
| 分析指令 | 语义核心摘要 |

#### 交互对象

DP 动态规划调度 Agent（仅通过调度节点收发数据）

#### 触发场景

- 用户输入新的对话内容，需要进行语义解析
- 历史对话批量打标任务执行时

#### 异常处理

- 语义置信度过低时，标记为待确认标签，返回调度节点由对话 Agent 引导用户澄清
- 文本过长时，自动分段分析后聚合结果

---

### 2.3 用户对话 Agent（Conversational Agent）

#### 核心定位

面向用户的交互响应生成核心，负责生成自然、共情、符合人设的对话回复，承接日常聊天、情绪安抚、结果告知等全场景交互。

#### 核心职责

1. 基于用户输入、语义标签与上下文，生成自然流畅的对话回复
2. 结合情绪标签输出共情性回应，匹配用户当前情绪状态
3. 对任务请求、咨询请求进行确认与引导，补充必要参数信息
4. 向用户同步任务执行进度、报告生成结果等系统通知
5. 配合合规要求调整回复语气与表达，避免不当表述

#### 核心能力

- 共情式对话生成
- 多轮对话上下文一致性保持
- 情绪适配的语气动态调节
- 任务 / 咨询场景的信息引导与确认

#### 输入输出规范

表格

| 输入 | 输出 |
| --- | --- |
| 用户原始对话内容 | 面向用户的最终对话回复文本 |
| 语言分析 Agent 输出的标签集 | 回复元数据（回复类型、情绪基调） |
| 检索 Agent 返回的 RAG 建议内容（如有） | - |
| 任务状态通知（如有） | - |

#### 交互对象

DP 动态规划调度 Agent

#### 触发场景

- 日常对话场景需要生成回复
- 任务进度 / 结果需要告知用户
- 合规校验不通过需要重生成回复

#### 异常处理

- 生成内容合规校验不通过时，接收调度指令进行定向重生成
- 上下文信息不足时，生成引导性话术补充信息

---

### 2.4 检索 Agent（Retrieval Agent）

#### 核心定位

系统的数据查询服务核心，提供双源检索能力：历史对话数据检索与 RAG 知识库检索，为对话回复、报告生成、画像构建提供数据支撑。

#### 核心职责

1. 根据检索指令，在历史对话数据库中检索相关聊天记录、标签数据
2. 针对用户的建议咨询需求，在 RAG 知识库中检索匹配的心理建议、情绪调节方法等内容
3. 对检索结果进行相关性排序、去重与片段聚合，返回最匹配的 TopN 结果
4. 支持多维度条件检索：按时间范围、情绪类型、关键词、事件主题过滤

#### 核心能力

- 历史对话语义检索与关键词检索
- RAG 知识库向量检索
- 检索结果重排序与相关性打分
- 多维度条件过滤检索

#### 输入输出规范

表格

| 输入 | 输出 |
| --- | --- |
| 检索关键词 / 语义向量 | 结构化检索结果列表（内容、相关性得分、元数据） |
| 检索范围限定（历史对话 / RAG 知识库 / 全部） | 检索结果核心摘要 |
| 过滤条件（时间、标签类型、数量限制） | - |

#### 交互对象

DP 动态规划调度 Agent

#### 触发场景

- 用户查询历史对话 / 情绪记录
- 生成建议需要调用 RAG 知识库
- 生成分析报告需要拉取历史数据
- 用户画像更新需要聚合历史标签

#### 异常处理

- 无检索结果时，返回空结果集并说明原因
- 检索超时时，返回兜底默认内容或提示用户重试

### 2.5 任务执行 Agent（Task Execution Agent）

#### 核心定位

系统的异步任务管理核心，负责全生命周期的任务管理与执行，支持定时任务、长周期任务、分步任务的调度与管控。

#### 核心职责

1. 接收任务指令，创建结构化任务记录，包含任务类型、需求描述、状态、创建时间、截止时间等
2. 对复杂任务进行步骤拆解，生成有依赖关系的子任务列表
3. 管理任务全生命周期：待执行、执行中、已完成、已失败、已取消
4. 支持定时任务与周期任务的触发执行（如每日情绪汇总、每周报告生成）
5. 向 DP 调度 Agent 同步任务状态与执行结果，触发后续通知流程
6. 支持任务暂停、取消、重试等操作

#### 核心能力

- 任务拆解与工作流编排
- 定时 / 周期任务调度
- 任务状态追踪与生命周期管理
- 子任务依赖管理

#### 输入输出规范

表格

| 输入 | 输出 |
| --- | --- |
| 任务类型与需求描述 | 任务创建成功回执 |
| 任务执行参数（时间、范围、格式等） | 任务状态更新通知 |
| 任务操作指令（创建、暂停、取消、重试） | 任务执行结果数据 |

#### 交互对象

DP 动态规划调度 Agent（任务指令与状态同步）

#### 触发场景

- 用户发起报告生成、数据统计等任务指令
- 定时 / 周期任务到达触发时间
- 任务步骤执行完成，推进到下一阶段

#### 异常处理

- 任务执行失败时，自动重试（可配置次数），重试失败标记为异常并通知调度
- 任务参数缺失时，返回调度节点由对话 Agent 引导用户补充

### 2.6 合规检查 Agent（Compliance Check Agent）

#### 核心定位

系统的安全合规守门员，负责全链路的内容安全与专业合规校验，保障输出内容合法、正向、无心理风险。

#### 核心职责

1. 校验用户输入内容，识别敏感词汇、违法违规内容、危险言论
2. 校验所有 Agent 输出给用户的内容，识别敏感信息、不当表述
3. 重点校验心理相关输出：禁止出现精神疾病诊断、医疗建议、负面引导、极端化表述
4. 识别自我伤害、伤害他人等高危风险意图，触发预警流程
5. 对不合规内容给出修改方向，引导对应 Agent 重生成

#### 核心能力

- 敏感词检测与过滤
- 违规内容分类识别
- 心理专业合规校验（禁止诊断、禁止医疗建议、负面内容管控）
- 高危风险识别与预警

#### 输入输出规范

表格

| 输入 | 输出 |
| --- | --- |
| 待校验的文本内容（用户输入 / 回复 / 报告 / 建议） | 合规校验结果（通过 / 不通过） |
| 文本类型标识 | 不合规内容类型与位置 |
| 校验指令 | 修改优化建议（可选） |

#### 交互对象

DP 动态规划调度 Agent

#### 触发场景

- 用户输入进入系统时，先进行输入合规校验
- 任意 Agent 生成待输出内容时，进行输出合规校验
- 报告生成完成后，进行全量内容合规校验

#### 异常处理

- 输入内容严重违规时，直接拦截并返回标准化拒绝回复
- 输出内容不合规时，返回调度节点触发对应 Agent 重生成
- 识别到自伤 / 伤人高危风险时，立即触发预警并输出正向干预内容

---

### 2.7 用户画像与报告 Agent（User Profile & Report Agent）【补充】

#### 核心定位

系统的数据价值输出核心，负责聚合历史标签数据构建用户人格画像，以及生成多维度的情绪与心理分析报告，是实现「自我回溯」核心价值的关键节点。

#### 核心职责

1. 基于语言分析 Agent 输出的标签，定期聚合更新用户人格画像，包含情绪特质、心理特征、行为模式等维度
2. 接收报告生成任务，拉取对应时间范围的历史对话与标签数据，进行统计分析
3. 生成结构化分析报告，包含情绪走势、心理特征变化、高频场景分析、优化建议等模块
4. 支持多维度报告：日报、周报、月报、自定义周期报告、专项主题报告
5. 维护用户画像的版本管理，支持人格变化纵向回溯对比

#### 核心能力

- 多维度用户画像构建与动态更新
- 情绪走势统计与可视化指标生成
- 人格特征纵向对比分析
- 结构化报告自动生成
- 多周期报告模板适配

#### 输入输出规范

表格

| 输入 | 输出 |
| --- | --- |
| 历史对话标签数据集 | 结构化用户画像数据 |
| 报告生成参数（时间范围、报告类型、重点维度） | 完整的分析报告内容（文本 + 统计指标） |
| 画像更新 / 报告生成指令 | 核心结论摘要 |

#### 交互对象

DP 动态规划调度 Agent

#### 触发场景

- 每日 / 每周 / 每月定时画像更新
- 用户触发生成分析报告任务
- 人格回溯查询需求

#### 异常处理

- 历史数据不足时，在报告中说明数据量限制，输出已有分析结论
- 报告生成失败时，返回任务执行 Agent 标记失败并重试
