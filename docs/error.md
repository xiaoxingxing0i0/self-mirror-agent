## 错误码设计规范

### 1.1 编码规则

错误码采用**6 位数字编码**，结构为：`错误级别(1位) + 模块编码(2位) + 具体错误编号(3位)`

示例：`101001` = 参数错误 + DP 调度模块 + 第 1 号参数错误

### 1.2 错误级别定义

表格

| 首位编码 | 级别 | 说明 |
| --- | --- | --- |
| 0 | 成功 | 请求处理成功 |
| 1 | 参数错误 | 请求参数非法、缺失、格式错误等 |
| 2 | 业务错误 | 业务逻辑校验不通过、业务规则限制等 |
| 3 | 权限认证错误 | 未登录、token 失效、权限不足等 |
| 4 | 资源不存在 | 请求的会话、任务、报告等资源不存在 |
| 5 | 系统错误 | 系统内部异常、程序运行错误等 |
| 6 | 第三方服务错误 | 大模型、数据库、中间件等外部服务异常 |

### 1.3 模块编码定义

表格

| 模块编码 | 模块名称 | 对应 Agent / 组件 |
| --- | --- | --- |
| 00 | 通用公共 | 全局通用错误 |
| 01 | 会话调度 | DP 动态规划调度 Agent |
| 02 | 语言分析 | 语言分析 Agent |
| 03 | 对话交互 | 用户对话 Agent |
| 04 | 信息检索 | 检索 Agent |
| 05 | 任务执行 | 任务执行 Agent |
| 06 | 合规校验 | 合规检查 Agent |
| 07 | 画像报告 | 用户画像与报告 Agent |
| 08 | 基础设施 | 数据库、缓存、中间件等 |
| 09 | 接口层 | Web 接口、WebSocket |
